# Games of Senses 🎮

**Games of Senses** — платформа клуба «Ігри Сенсів» для проведения онлайн-игр:
видеокомната на LiveKit, чат, голосования, таймеры, монеты и влияние, комнаты
для разговоров, лента сообщества.

Подробное описание устройства и принятых решений — в [CLAUDE.md](CLAUDE.md),
все эндпоинты и события сокета — в [API_REFERENCE.md](API_REFERENCE.md),
запуск за 10 минут — в [QUICK_START.md](QUICK_START.md).

## Что умеет

- **Игры**: создание и редактирование, регистрация игроков и зрителей, коды
  входа (код игры — место с голосом, код зрителя — место без голоса).
- **Комната**: видео и звук (LiveKit), публичный и личный чат, реакции,
  поднятая рука, голосования (в т. ч. анонимные и для зрителей), таймеры,
  монеты и банк, влияние, объявления, показ картинок, комнаты для разговоров,
  приглушение участников, заметки ведущего.
- **Запись игры**: ведущий нажимает «Почати запис» прямо в комнате — с
  компьютера или телефона. Браузер ведущего собирает видео всех участников в
  сетку, сводит голоса и по частям загружает запись в Cloudflare R2 (для
  слабых телефонов — «лише голос»). Если связь оборвётся, сохранится всё
  загруженное. Ссылка приходит ведущему в Telegram, файл удаляется через
  7 дней. При платном тарифе LiveKit можно переключиться на запись на
  серверах LiveKit (`RECORDING_MODE=egress`).
- **Telegram-бот** (только новости, не для переписки): анонс каждой новой
  игры всем подключённым (название, описание, дата и время, платная или нет,
  ведущий), коды входа при регистрации игроком или зрителем, заметки после
  игры, ссылки на записи, ссылка для восстановления пароля. `/stop` —
  отключить анонсы, `/news` — включить. Почтовых рассылок в проекте нет.
- **Показ экрана**: игроки и ведущий (не зрители), с компьютера.
- **Сообщество**: посты, комментарии, лайки в реальном времени.
- **Аккаунт**: email + пароль или Google, экспорт данных, удаление аккаунта.

## Архитектура

| | |
|---|---|
| Backend (`/back`) | Node.js 18+, Express 4, TypeScript, MongoDB (Mongoose), Socket.IO, livekit-server-sdk, zod, helmet, winston, Sentry |
| Frontend (`/front`) | React 18, TypeScript, Vite, TailwindCSS, React Router 6, Socket.IO client, LiveKit Components, i18next (uk/en) |
| Сервисы | MongoDB Atlas, LiveKit Cloud (видео), Cloudflare R2 (записи), Cloudinary (картинки), Telegram Bot API, Google Sign-In |

Бэкенд рассчитан на **один экземпляр**: состояние комнат и опрос Telegram
живут в памяти процесса.

## Запуск

```bash
cd back && npm ci && cp .env.example .env   # заполнить .env
npm run dev                                  # http://localhost:5000

cd front && npm ci && cp .env.example .env
npm run dev                                  # http://localhost:5173
```

Переменные окружения описаны в `back/.env.example` и `front/.env.example`.

## Проверки

```bash
cd back  && npm test && npx tsc --noEmit
cd front && npx vitest run && npx tsc --noEmit && npm run build
```

## Развёртывание

- **Backend** — Render (или любой хостинг Node с одним экземпляром):
  `npm ci && npm run build`, старт `npm start`. Прокси должен передавать
  `X-Forwarded-For`.
- **Frontend** — Vercel: статическая сборка `dist/`, настройки в
  `front/vercel.json` (SPA-переадресация и заголовки безопасности).
